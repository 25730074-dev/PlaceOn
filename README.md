## 1. 프로젝트 소개
위치와 사용자 취향을 기반으로 주변 장소를 탐색하고
개인에게 적합한 장소를 추천하는 모바일 웹 서비스입니다.

사용자는 현재 위치 또는 검색 조건을 기준으로 장소를 탐색하고,
장소 정보를 비교한 후 방문할 장소를 결정할 수 있습니다.



## 2. PRD

### 2.1. Problem
기존 지도·장소 검색 서비스에서는 사용자가 원하는 장소를 찾기 위해
여러 검색 결과를 직접 비교해야 합니다.

특히 동일한 지역에 많은 장소가 존재하는 경우
사용자의 개인적인 취향이나 선호 조건을 반영하여
장소를 선택하기 어렵다는 문제가 있습니다.

### 2.2. Goal
사용자의 위치와 취향을 바탕으로 적합한 장소를 우선적으로 탐색할 수 있도록
하여 장소 선택에 필요한 탐색 및 비교 과정을 줄이는 것을 목표로 합니다.

### 2.3. Target User
- 주변 장소를 자주 탐색하는 사용자
- 약속이나 외출 시 방문할 장소를 결정하기 어려운 사용자
- 자신의 취향에 맞는 장소를 우선적으로 확인하고 싶은 사용자

### 2.4. Solution
사용자의 취향을 저장하고 현재 위치 또는 검색 조건을 기준으로
장소를 탐색할 수 있도록 합니다.

검색 결과에서는 카테고리, 세부 업종, 지역, 층 등의 조건을 적용할 수 있으며,
장소 상세 화면에서 장소 정보를 확인하고 즐겨찾기에 저장할 수 있도록 합니다.

### 2.5. Core Value
사용자가 수많은 장소를 직접 탐색하는 대신
자신의 위치와 취향을 기준으로 적합한 장소를 빠르게 발견하고
비교·선택할 수 있도록 하는 것입니다.
